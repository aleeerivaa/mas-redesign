# MAS S.r.l. Website Redesign

Complete modern redesign of the MAS S.r.l. website - a professional company specializing in vertical mobility solutions.

## Technology Stack

- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: CSS Modules + Tailwind CSS
- **Optimization**: Image optimization, lazy loading, semantic HTML

## Getting Started

### Prerequisites

- Node.js 16.x or higher
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```
